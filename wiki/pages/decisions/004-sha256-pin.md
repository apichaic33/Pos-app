# TD-004: เก็บ PIN เป็น SHA-256 Hash

## การตัดสินใจ
```js
const PIN_SALT = 'POS_APP_SALT_2025';
async function hashPin(pin){
  const msg = PIN_SALT + pin;
  const buf = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(msg));
  return Array.from(new Uint8Array(buf)).map(b=>b.toString(16).padStart(2,'0')).join('');
}
```
PIN จริงไม่เก็บที่ไหน — เก็บแต่ hash 64 hex chars

## เหตุผล
- PIN plain-text อ่านได้จาก localStorage / Google Sheets ทันที
- ใช้ Web Crypto API (built-in browser) ไม่ต้องการ library
- Salt ป้องกัน rainbow table attack

## Migration
`migratePins()` ใน `init.js` — ตรวจ PIN เก่า (ไม่ใช่ 64 hex) → hash ครั้งเดียวตอน boot → `saveLocal()`

## ข้อจำกัด
- Fixed salt ต่อ app — ถ้า salt หลุดออกไป brute-force ง่ายขึ้น
- 4-digit PIN มีแค่ 10,000 ความเป็นไปได้ — จำกัดด้วย brute-force lockout แทน
- ไม่ใช้ bcrypt/argon2 เพราะ Web Crypto ไม่รองรับ และ 4-digit PIN ก็ไม่ใช่ secret ที่ต้องการความปลอดภัยสูง
